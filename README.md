# Quick-Query - macOSショートカットアプリ

macOS用のクイックLLM質問アプリです。**Cmd+C+C**で選択したテキストをOllamaに送信し、即座に結果をポップアップで表示します。翻訳、要約、質問など、あらゆるLLMタスクをショートカットで素早く実行できます。

## 主な特徴

- ⚡ **超高速アクセス**: Cmd+C+Cで選択テキストを即座にLLMに送信
- 🎯 **シンプルな操作**: キーボードショートカットだけで完結
- 🔧 **柔軟な設定**: モデル選択、カスタムプロンプト、複数プロンプトの保存
- 💾 **永続化設定**: 選択したモデルやプロンプトが自動保存
- 📋 **ワンクリックコピー**: 結果をクリップボードに簡単コピー
- 🖥️ **マルチデスクトップ対応**: どの仮想デスクトップでも表示

## 機能

- **Cmd+C+C**: 選択テキストをLLMに送信して結果を表示
- **モデル選択**: ローカルにインストール済みのOllamaモデルから選択
- **カスタムプロンプト**: System Promptを自由にカスタマイズ
- **プロンプト管理**: 複数のプロンプトを保存・切り替え可能
- **クリップボードコピー**: 結果をワンクリックでコピー
- **ポップアップ表示**: カーソル位置に結果を表示（フォーカスを奪わない）

## セットアップ

### 1. 依存関係をインストール

```bash
cd quick-query
npm install
# または
pnpm install
```

### 2. Ollamaの起動確認

Ollamaがローカルで起動していることを確認してください:

```bash
# Ollamaが http://127.0.0.1:11434 で起動している必要があります
ollama serve
```

### 3. モデルのインストール（初回のみ）

使用したいモデルをOllamaにインストール:

```bash
ollama pull cogito:14b
# またはお好みのモデル
ollama pull llama2
ollama pull mistral
```

### 4. アプリを起動

```bash
npm start
# または
pnpm start
```

## 使用方法

1. **アプリを起動**（バックグラウンドで実行されます）
2. **テキストを選択**（ブラウザ、エディタ、どこでも）
3. **Cmd+C+Cを押す**（Cmd+Cを2回連続で押す）
4. **結果がポップアップで表示**されます

### 設定画面の使い方

⚙️ボタンをクリックして設定画面を開きます:

- **Ollamaモデル**: 使用するモデルを選択
- **保存済みプロンプト**: 保存したプロンプトから選択
- **プロンプト名**: 新規プロンプトを保存する際の名前
- **System Prompt**: プロンプトを編集
- **保存**: プロンプトを保存（名前を入力すると新規保存、入力しないと現在のプロンプトを更新）
- **削除**: 選択中のプロンプトを削除（デフォルトは削除不可）

## 設定

### モデルの選択

設定画面（⚙️）から、ローカルにインストール済みのOllamaモデルを選択できます。選択したモデルは自動的に保存され、次回起動時も使用されます。

### プロンプトのカスタマイズ

1. 設定画面を開く
2. 「保存済みプロンプト」から編集したいプロンプトを選択
3. 「System Prompt」を編集
4. 「保存」をクリック（名前を入力すると新規保存）

### デフォルトプロンプト

デフォルトでは翻訳用のプロンプトが設定されていますが、以下のような用途にも使えます:

- **要約**: "Summarize the following text in a few sentences:"
- **質問**: "Answer the following question:"
- **コード説明**: "Explain the following code:"
- **その他**: 自由にカスタマイズ可能

## ビルド

macOSアプリとしてビルドする場合:

```bash
npm run build
# または
pnpm run build
```

ビルドされたアプリは `dist` ディレクトリに生成されます。

## トラブルシューティング

### Ollamaに接続できない

- Ollamaが起動しているか確認: `ollama list`
- ホストが正しいか確認（デフォルト: `http://127.0.0.1:11434`）

### モデルが見つからない

- モデルがインストールされているか確認: `ollama list`
- 設定画面でモデルリストを更新

### ショートカットが動作しない

- アプリが起動しているか確認
- 他のアプリが同じショートカットを使用していないか確認
- アクセシビリティ権限が許可されているか確認

### Electronのインストールエラー

```bash
rm -rf node_modules
npm install
# または
pnpm install
```
