# Quick-Query 要件定義書

- 作成日: 2026-10-08
- 版数: 0.2（ショートカットを Cmd+C+C に確定。以後の設計は現行実装に依存せず `docs/design.md` でゼロから行う）
- 作成者: oyako-li

> v0.1 は既存実装からの逆起こし。v0.2 で「現状」列を外し、理想仕様（to-be）に統一した。

## 1. 背景と目的

### 背景・課題
- 外国語テキストの翻訳や要約など、LLM への軽い質問のたびに、ブラウザや別アプリを開いてコピー&ペーストする手間がある。
- 外部クラウド API に送ると、機密テキストの送信や従量課金が気になる。

### 目的
macOS 上で、どのアプリでも選択したテキストをショートカット一発でローカル LLM（Ollama）に送り、結果をカーソル付近のポップアップで即座に得られるようにする。

### ゴール（成功条件）
- テキスト選択からショートカット操作だけで結果表示まで完結する（アプリ切替・ペースト不要）。
- 通信先はローカルの Ollama（`http://127.0.0.1:11434`）のみ。テキストを外部に送らない。
- 用途（翻訳・要約・質問・コード説明）を System Prompt の切替で変えられる。
- 作業中のアプリからフォーカスを奪わない。

## 2. 利用者と権限

| 役割 | 人数 | できること | 見えるデータ |
|---|---|---|---|
| エンドユーザー（開発者本人） | 1 | ショートカット実行、モデル・プロンプト・ホットキー設定、結果コピー | 自 Mac 上の選択テキストと LLM 出力、ローカル保存設定 |

- 単一ユーザー、ローカル完結。アカウント・認証・マルチユーザー機能は無い。
- 前提: macOS、Ollama 起動済み、使用モデルを `ollama pull` 済み、アクセシビリティ権限を付与済み。

## 3. データ定義

| データ | 保存先 | 内容 |
|---|---|---|
| `systemPrompt` | electron-store | 現在の System Prompt（初期値: 翻訳用） |
| `savedPrompts` | electron-store | `{ id, name, prompt }` の配列。初期値は `{ id:'default', name:'翻訳' }` |
| `currentPromptId` | electron-store | 選択中プロンプト ID（初期値 `default`） |
| `selectedModel` | electron-store | 使用 Ollama モデル名（初期値 `cogito:14b`） |
| `hotkey` | electron-store | グローバルショートカット（初期値 `Alt+Z`） |
| 直近の結果 | メモリのみ | コピー機能用。永続化しない |

選択テキスト・LLM 出力は永続化しない。

## 4. 機能要件

優先度は MoSCoW。状態は現行実装に対するもの。

| ID | 機能名 | 概要 | 起動方法 | 優先度 |
|---|---|---|---|---|
| F-01 | 選択テキスト取得 | Cmd+C 自体が OS のコピーを行うので、その結果のクリップボード文字列を取得対象とする。アプリが追加でキーを送出したり、クリップボードを書き換えたりしない | F-02 内部 | Must |
| F-02 | Cmd+C+C 起動 | Cmd を押したまま C を 400ms 以内に2回押すと実行（既定。間隔は設定可）。1回目は通常のコピーとして OS にそのまま通す（キー入力を奪わない・遅延させない） | キー入力監視 | Must |
| F-03 | LLM 問い合わせ | 選択テキストを Ollama `chat`（ストリーミング）へ送信。プロンプトは `system` と `userTemplate`（`{{text}}` 置換）の組で、固定指示は持たない | F-02 | Must |
| F-04 | ポップアップ表示 | カーソル付近に常時最前面で表示。フォーカスを奪わない。全デスクトップ・フルスクリーン上に表示。トークンを逐次描画。実行中は表示中の内容をクリアしてスピナー | F-02 | Must |
| F-05 | 中断・閉じる | Esc または外側クリックで閉じる。生成中なら Ollama への要求を中断。新しい Cmd+C+C は進行中の要求を中断して置き換える | UI | Must |
| F-06 | エラー表示 | Ollama 未起動、モデル未取得、選択なし、権限不足を原因別の文言と対処ボタン付きで表示 | F-02 | Must |
| F-07 | 結果コピー | ワンクリックまたは `Cmd+Shift+C` | UI | Must |
| F-08 | モデル選択 | `ollama list` から選択、永続化。モデル未取得時は `ollama pull` コマンドを案内 | 設定画面 | Must |
| F-09 | プロンプト管理 | 複数プロンプトの作成・編集・複製・削除・切替。組込みプロンプト（翻訳、要約、説明）は削除不可で、複製して編集する | 設定画面 / ポップアップ内セレクト | Must |
| F-10 | 初回セットアップ | 必要権限（入力監視、アクセシビリティ）と Ollama 接続状態を順にチェックし、付与手順を案内 | 初回起動 / トレイ | Must |
| F-11 | 常駐 | メニューバー（トレイ）常駐、Dock 非表示。トレイから設定、一時停止/再開、終了。ログイン時自動起動を選択可 | トレイ | Must |
| F-12 | トリガー設定 | 二度押し間隔の調整。トリガーの一時無効化 | 設定画面 | Should |
| F-13 | 代替ホットキー | Cmd+C+C が使えない環境向けに、通常のグローバルショートカット（例 `Alt+Z`）を追加で割当可 | 設定画面 | Could |
| F-14 | 配布ビルド | 署名・公証済み `.dmg`（Apple Developer ID があれば）。なければ未署名ビルド手順 | `npm run build` | Should |

## 5. 非機能要件

### 性能
- ショートカットから「Querying...」表示までは体感即時（目標 < 0.5 秒）。
- 結果表示までの時間は Ollama モデルの推論速度に依存。非ストリーム応答のため、完了まで本文は出ない（改善候補、Could）。
- 選択テキスト取得のタイムアウトは約1秒（100ms × 10）。

### セキュリティ・プライバシー
- 通信先は `127.0.0.1:11434` のみ。外部送信なし。
- ログ（`console.log`）に翻訳結果と System Prompt が出る。機密テキストを扱う場合はログ出力の抑制を検討（TBD-3）。
- レンダラは `nodeIntegration: true` / `contextIsolation: false` で `webviewTag` 有効。ローカル生成 HTML のみ読み込む前提だが、Web ページを表示する機能を足す場合は要見直し（TBD-4）。
- 必要権限: アクセシビリティ（グローバルショートカット・選択取得・AppleScript による Cmd+C 送出）。

### 互換性・環境
- macOS 専用（AppleScript 依存）。Electron ^28、Node ESM。
- 依存: `ollama`、`electron-store`、`node-get-selected-text`、`@xitanggg/node-selection`。

### 運用・保守
- 配布・監視・サポート体制なし。個人利用のためログはコンソールのみ。
- 起動は `npm run dev` / ビルド済みアプリ。自動起動（ログイン項目）は未対応。

## 6. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| Ollama 未起動・モデル未取得 | 全機能が失敗 | エラー文言で案内。起動チェックと手順の明示を検討 |
| 他アプリとのホットキー衝突 | 起動しない | 設定で変更可。登録失敗時は `Alt+Z` へフォールバック |
| クリップボード経由取得中の上書き | ユーザーのクリップボードが一時的に変わる | 実行後に元の内容を復元済み。失敗経路でも復元 |
| 選択取得が一部アプリで失敗（Electron/一部ターミナル等） | 「テキストが選択されていません」 | 2段構えのフォールバックを維持。非対応アプリは README に記載 |
| 大きなモデルで応答が遅い | 待たされる | ストリーム表示、軽量モデルの選択を案内 |
| `nodeIntegration` 有効 | Web コンテンツ表示時に任意コード実行リスク | 外部コンテンツを表示しない。拡張時は preload + contextIsolation へ移行 |
| 長大な選択テキスト | コンテキスト超過・遅延 | 文字数上限と警告を検討（TBD-5） |

## 7. スコープ外（Won't）

- Windows / Linux 対応
- クラウド LLM（OpenAI 等）への接続
- マルチユーザー、アカウント、設定の同期
- チャット履歴の保存・会話の継続（単発問い合わせのみ）
- 画像・ファイル入力
- Web Crawler Tool / Ollama Tools 連携（v1 では行わない。将来検討）
